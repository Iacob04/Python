RA4 · Programación Orientada a Objetos

Clases, objetos, herencia, encapsulación y clases abstractas en Python.

1Clase, objeto y constructor __init__

Una clase es la plantilla; un objeto es una instancia concreta creada a partir de ella.

  • __init__ es el constructor: se ejecuta automáticamente al crear el objeto.
  • self representa al propio objeto (como this en Java). Es siempre el primer parámetro.
  • Un parámetro como nivel=1 tiene valor por defecto: si no lo pasas, vale 1.
class Pokemon:
    def __init__(self, nombre, tipo, nivel=1):   # constructor
        self.nombre = nombre        # atributo público
        self.tipo   = tipo
        self.nivel  = nivel
        self.vida   = nivel * 10     # atributo calculado

# Instanciar = crear un objeto
pikachu = Pokemon("Pikachu", "Eléctrico", 5)
print(pikachu.nombre)   # Pikachu

2Métodos de instancia y __str__

Los métodos son funciones dentro de la clase; siempre reciben self primero. __str__ define qué se muestra al hacer print(objeto) (es el toString() de Java).

Clave del examen__str__ siempre lleva return, nunca print. Y cuidado con escribirlo bien: __str__, no __srt__ (ese error baja nota).
class Pokemon:
    def __init__(self, nombre, nivel=1):
        self.nombre = nombre
        self.nivel  = nivel

    def subir_nivel(self):          # método de instancia
        self.nivel += 1

    def __str__(self):              # se llama con print(objeto)
        return f"Pokemon({self.nombre}, nivel={self.nivel})"

p = Pokemon("Charmander", 3)
p.subir_nivel()
print(p)   # Pokemon(Charmander, nivel=4)

3Encapsulación: @property y @setter

Permiten leer (getter) y modificar (setter) atributos protegidos con control. Se usan sin paréntesis, como un atributo normal.

NotaciónNivelSignificado
nombrePúblicoAcceso libre desde fuera
_edadProtegido1 guion bajo · accesible en subclases (convención)
__edadPrivado2 guiones bajos · solo dentro de su clase
class Entrenador:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self._edad  = edad        # _ = protegido

    @property                     # GETTER → leer
    def edad(self):
        return self._edad

    @edad.setter                 # SETTER → escribir con control
    def edad(self, nueva):
        if nueva < 0:
            print("La edad no puede ser negativa.")
        else:
            self._edad = nueva

ash = Entrenador("Ash", 10)
print(ash.edad)   # getter → 10 (sin paréntesis)
ash.edad = -5      # setter → "La edad no puede ser negativa."
ash.edad = 11      # setter → asigna 11

4@staticmethod y @classmethod

  • @staticmethod: no recibe self ni cls. Es una función agrupada en la clase.
  • @classmethod: recibe cls (la clase en sí), no el objeto.
  • Ambos se llaman desde la clase: NombreClase.metodo(), sin crear objeto.
class Pokemon:
    @staticmethod
    def descripcion():            # sin self
        return "Criaturas con habilidades."

    @classmethod
    def listar(cls, lista):       # recibe cls
        for p in lista:
            print(p)

print(Pokemon.descripcion())   # sin crear objeto

5Herencia, super() y isinstance()

class Hija(Padre) hace que Hija herede atributos y métodos de Padre. super().__init__(...) llama al constructor del padre (obligatorio si la hija tiene su propio __init__).

  • Sobreescribir (override): redefinir un método del padre en la hija.
  • isinstance(obj, Clase): devuelve True/False según el tipo. Útil para poner límites.
class Animal:
    def __init__(self, nombre, nacimiento):
        self.nombre = nombre
        self.nacimiento = nacimiento

class Perro(Animal):                  # Perro hereda de Animal
    def __init__(self, nombre, nacimiento, vacunado):
        super().__init__(nombre, nacimiento)  # constructor del padre
        self.vacunado = vacunado            # atributo propio

    def __str__(self):                    # sobreescribe (override)
        estado = "vacunado" if self.vacunado else "sin vacunar"
        return f"Perro({self.nombre}, {estado})"

tobi = Perro("Tobi", 2020, True)
print(isinstance(tobi, Perro))    # True
print(isinstance(tobi, Animal))   # True (por herencia)

6Clase abstracta: ABC + @abstractmethod

Una clase abstracta no se puede instanciar; sirve de base. @abstractmethod obliga a las subclases a implementar ese método.

from abc import ABC, abstractmethod

class Personaje(ABC):              # no instanciable
    def __init__(self, nombre):
        self._nombre = nombre

    @property
    def nombre(self):
        return self._nombre

    @abstractmethod
    def __str__(self):              # cada hija DEBE definirlo
        pass

class Heroe(Personaje):
    def __init__(self, nombre, poder):
        super().__init__(nombre)
        self.__poder = poder       # privado

    def __str__(self):
        return f"{self._nombre} - {self.__poder}"

4Los ? parametrizados (¡cae seguro!)

Los ? son marcadores de posición; los valores van en una tupla como segundo argumento de execute().

Por qué se usan1) Evitan la inyección SQL (seguridad / integridad).  2) Manejan bien comillas y tipos automáticamente.
Trampa clásicaCon un solo parámetro, la coma de la tupla es obligatoria: (id_libro,) es una tupla, (id_libro) no lo es y da error.
# ✅ CORRECTO
cursor.execute("SELECT * FROM libros WHERE autor = ?", (autor,))
cursor.execute("DELETE FROM libros WHERE id = ?", (id_libro,))   # ← la coma

# ❌ MAL — vulnerable a inyección SQL
cursor.execute(f"SELECT * FROM libros WHERE autor = {autor}")

5fetchall() vs fetchone()

  • fetchall(): devuelve una lista con todas las filas. Para listados.
  • fetchone(): devuelve solo la primera fila. Para un único resultado (ej: una media).
  • cursor.lastrowid: el id que SQLite asignó al último INSERT (útil para enlazar tablas).
registros = cursor.fetchall()   # LISTA de todas las filas
una_fila  = cursor.fetchone()   # SOLO la primera fila

# obtener el id recién insertado
cursor.execute("INSERT INTO alumnos (nombre) VALUES (?)", (nombre,))
conexion.commit()
nuevo_id = cursor.lastrowid

7Relaciones entre tablas: FOREIGN KEY

La parte central de "mantener la integridad". Una tabla se relaciona con otra mediante una clave foránea: un campo que debe corresponder a una clave que exista en la otra tabla.

cursor.execute("""
    CREATE TABLE IF NOT EXISTS notas (
        id         INTEGER PRIMARY KEY AUTOINCREMENT,
        id_alumno  INTEGER NOT NULL,
        asignatura TEXT NOT NULL,
        nota       REAL NOT NULL,
        FOREIGN KEY (id_alumno) REFERENCES alumnos(id)
    )
""")
Integridad al borrarBorra primero los "hijos" y luego el "padre". Si no, las filas hijas quedan huérfanas (apuntan a algo que ya no existe).
def eliminar_alumno(id_alumno):
    cursor.execute("DELETE FROM notas WHERE id_alumno = ?", (id_alumno,))   # 1º hijos
    cursor.execute("DELETE FROM alumnos WHERE id = ?", (id_alumno,))        # 2º padre
    conexion.commit()

2. Herencia + property

Crea una clase Empleado con nombre y _salario (con getter y setter que no permita salarios negativos). Crea una subclase Gerente que añada departamento y sobreescriba __str__. Usa super().

class Empleado:
    def __init__(self, nombre, salario):
        self.nombre   = nombre
        self._salario = salario

    @property
    def salario(self):
        return self._salario

    @salario.setter
    def salario(self, valor):
        if valor < 0:
            print("El salario no puede ser negativo.")
        else:
            self._salario = valor

    def __str__(self):
        return f"{self.nombre}: {self._salario}€"

class Gerente(Empleado):
    def __init__(self, nombre, salario, departamento):
        super().__init__(nombre, salario)
        self.departamento = departamento

    def __str__(self):
        return f"{self.nombre} ({self.departamento}): {self._salario}€"

g = Gerente("Lucía", 3000, "Ventas")
g.salario = -100          # El salario no puede ser negativo.
print(g)                  # Lucía (Ventas): 3000€

3. Clase abstracta Figura

Crea una clase abstracta Figura con un método abstracto area(). Crea Cuadrado (lado) y Circulo (radio) que lo implementen. Mete las dos en una lista y recorre imprimiendo cada área.

from abc import ABC, abstractmethod

class Figura(ABC):
    @abstractmethod
    def area(self):
        pass

class Cuadrado(Figura):
    def __init__(self, lado):
        self.lado = lado
    def area(self):
        return self.lado ** 2

class Circulo(Figura):
    def __init__(self, radio):
        self.radio = radio
    def area(self):
        return 3.1416 * self.radio ** 2

figuras = [Cuadrado(4), Circulo(3)]
for f in figuras:
    print(round(f.area(), 2))   # 16   28.27

9. Flota de vehículos (todo junto: abstracta + classmethod + staticmethod + isinstance)

Clase abstracta Vehiculo con _matricula y property precio_dia (setter que no admita ≤ 0). Métodos abstractos __str__ y coste_alquiler(dias). Tres subclases (Coche +5€/día si GPS, Moto normal, Furgoneta +20% si carga > 1000kg). Un @classmethod flota_mas_cara, un @staticmethod es_matricula_valida, y una clase Cliente que con isinstance no deje alquilar más de 2 furgonetas. Si resuelves esto, el examen te sobra.

from abc import ABC, abstractmethod

class Vehiculo(ABC):                       # clase abstracta (no instanciable)
    def __init__(self, matricula, precio_dia):
        self._matricula = matricula        # protegido (_)
        self.precio_dia = precio_dia       # pasa por el setter de abajo

    @property                            # GETTER
    def precio_dia(self):
        return self._precio_dia

    @precio_dia.setter                   # SETTER con validación
    def precio_dia(self, valor):
        if valor <= 0:
            print("Precio no válido")
        else:
            self._precio_dia = valor

    @abstractmethod
    def __str__(self): pass          # cada hija lo define

    @abstractmethod
    def coste_alquiler(self, dias): pass

    @classmethod                         # opera sobre una LISTA
    def flota_mas_cara(cls, lista):
        return max(lista, key=lambda v: v.precio_dia)

    @staticmethod                        # sin self ni cls
    def es_matricula_valida(matricula):
        return len(matricula) == 7

class Coche(Vehiculo):
    def __init__(self, matricula, precio_dia, num_puertas, tiene_gps):
        super().__init__(matricula, precio_dia)
        self.__num_puertas = num_puertas    # privado (__)
        self.__tiene_gps = tiene_gps
    def __str__(self):
        gps = "Sí" if self.__tiene_gps else "No"
        return f"COCHE {self._matricula} - {self.precio_dia}€/día - GPS: {gps}"
    def coste_alquiler(self, dias):
        coste = self.precio_dia * dias
        if self.__tiene_gps:
            coste += 5 * dias               # +5€/día por GPS
        return coste

class Moto(Vehiculo):
    def __init__(self, matricula, precio_dia, cilindrada):
        super().__init__(matricula, precio_dia)
        self.__cilindrada = cilindrada
    def __str__(self):

10. Las 5 preguntas tipo (tienda de videojuegos)

Tabla juegos: id (PK autoincrement), titulo, plataforma, precio (REAL), stock (INT), oferta (INT, 0/1 por defecto 0). Este es el patrón EXACTO que entra: crear con integridad, insertar con ?, filtrar con WHERE+ORDER BY, actualizar y agrupar con GROUP BY.

import sqlite3

# P1 · CREAR TABLA con integridad
def ejercicio1():
    conexion = sqlite3.connect("tienda.db")
    cursor = conexion.cursor()
    cursor.execute("""
        CREATE TABLE IF NOT EXISTS juegos (
            id         INTEGER PRIMARY KEY AUTOINCREMENT,
            titulo     TEXT    NOT NULL,
            plataforma TEXT    NOT NULL,
            precio     REAL    NOT NULL,
            stock      INTEGER NOT NULL,
            oferta     INTEGER NOT NULL DEFAULT 0)
    """)
    # PRIMARY KEY → id único · NOT NULL → obligatorio · DEFAULT 0 → valor por defecto
    conexion.commit()          # confirma (crea estructura)
    conexion.close()

# P2 · INSERTAR con parámetros ?
def ejercicio2():
    conexion = sqlite3.connect("tienda.db")
    cursor = conexion.cursor()
    juegos = [
        ("Zelda TOTK", "Switch", 59.99, 15, 0),
        ("Animal Crossing", "Switch", 39.99, 8, 0),
        ("Mario Kart 8", "Switch", 35.00, 20, 0)]
    # Los ? evitan inyección SQL: el valor entra como dato, nunca como código
    cursor.executemany("INSERT INTO juegos (titulo,plataforma,precio,stock,oferta) VALUES (?,?,?,?,?)", juegos)
    conexion.commit()          # OBLIGATORIO tras INSERT
    conexion.close()

# P3 · CONSULTAR con filtro (Switch < 40€, de barato a caro)
def ejercicio3():
    conexion = sqlite3.connect("tienda.db")
    cursor = conexion.cursor()
    cursor.execute("""
        SELECT titulo, precio FROM juegos
        WHERE plataforma = ? AND precio < 40
        ORDER BY precio ASC
    """, ("Switch",))      # tupla con coma ← OJO
    for juego in cursor.fetchall():
        print(juego)
    conexion.close()          # SELECT: sin commit

# P4 · ACTUALIZAR (oferta=1 si stock>10)
def ejercicio4():
    conexion = sqlite3.connect("tienda.db")
    cursor = conexion.cursor()
    cursor.execute("UPDATE juegos SET oferta = ? WHERE stock > ?", (1, 10))
    conexion.commit()          # OBLIGATORIO tras UPDATE
    conexion.close()

# P5 · ESTADÍSTICAS (cuántos por plataforma)
def ejercicio5():
    conexion = sqlite3.connect("tienda.db")
    cursor = conexion.cursor()
    cursor.execute("SELECT plataforma, COUNT(*) FROM juegos GROUP BY plataforma")
    for juego in cursor.fetchall():
        print(juego)
    conexion.close()          # SELECT: sin commit
